AI-PsychosisBench

AI-PsychosisBench measures repeat mistakes by coding agents with memory. It is not a mental-health benchmark and is not related to psychosis-bench (arXiv 2509.10970).

Each number is a difference in the share of lessons a Claude Code agent fails on the first try, with its 95% interval. Below zero is better. Learns is the memory minus the same memory with a new namespace for each task, so it shows whether the memory carries lessons. Vs built-in is the memory minus Claude Code's built-in memory.
